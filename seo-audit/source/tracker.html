4 · The speed check (Task 4)

Go to pagespeed.web.dev, choose the Mobile tab, and test this address:

https://marketeersresearch.com/blog/the-role-of-ai-data-analytics-in-fmcg-growth-a-roadmap-for-revenue-optimization/

Find the figure labelled LCP or Largest Contentful Paint. It was 4.9 seconds before this work. Anything lower is progress. Under 2.5 seconds is the goal and we will not reach it this week.

5 · Clearing the cache — both, every time

WhereHow
WordPressLeft menu → WP-Optimize → Cache → Purge cache
Sucuri firewallLog in → Clear cache

If you only clear one, the website keeps showing the old version and you will think the fix failed. This is the single most common reason a task looks like it did not work.
