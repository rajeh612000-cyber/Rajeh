# Super Bock Pricing Simulator — video walkthrough

`output/super-bock-pricing-simulator-walkthrough.mp4` is a silent screen recording
of the pricing simulator dashboard, generated by driving a real browser through
all four sections (Price Optimization, Price Simulation "What If?",
Price-Pack Architecture, Data Hub & Trust) so every slider, tab, dropdown and
chart animates exactly as it does live — same colors, fonts and layout as the
source HTML, nothing redrawn or reinterpreted.

## Files

- `source.html` — the original dashboard, unmodified, loading fonts/Chart.js from
  their public CDNs.
- `render.html` — identical markup and logic, but points at the bundled
  `fonts-local.css` / `fonts/` / `chart.umd.min.js` instead of external CDNs.
  This copy is what actually gets recorded, so the capture never depends on
  network access. (One CDN this sandbox's egress policy blocks —
  `cdnjs.cloudflare.com` — is swapped for the identical Chart.js 4.4.1 build
  fetched from the npm registry instead.)
- `record.js` — Playwright script: launches Chromium with video recording on,
  injects a small on-screen indicator so cursor-driven interactions (slider
  drags, clicks, dropdown selections, scrolling) are visible in the recording,
  and scripts a walkthrough of every panel.
- `output/*.mp4` — the rendered result (h264/yuv420p, no audio track).

## Regenerating

```
npm install playwright   # or ensure it's available on NODE_PATH
node record.js           # writes video-out/walkthrough.webm
ffmpeg -i video-out/walkthrough.webm -c:v libx264 -pix_fmt yuv420p -crf 18 \
  -preset slow -movflags +faststart -an output/super-bock-pricing-simulator-walkthrough.mp4
```

## Known deliberate substitution

The sidebar's embedded base64 PNG logo (~50KB of image data pasted inline in
the original HTML) was replaced with an inline SVG wordmark using the same
white card, ink-navy/teal/rust palette and serif/sans pairing as the rest of
the design. Every other color, font, layout rule and interactive behavior is
untouched.
